FAQ

常见问题

一定要联网才能用吗？
不需要。只有首次登录激活、以及点「检查更新」时需要网络。日常翻内容、复制命令、做本地实验都可以断网进行。
支持 macOS 或 Linux 桌面吗？
当前只提供 Windows 10 / 11 64 位安装包，原生 Windows 桌面程序，不是网页。其它系统暂未提供。
以后更新要重新下载安装包吗？
不用。软件内点「检查更新」即可下载并安装新版本，学习内容和进度都会保留。也可以在本页重新下载最新安装包覆盖安装。
换电脑了，内容还在吗？
用同一账号登录即可继续使用，学习进度按账号记录；账号与激活状态跟随你的账号，不绑定单台机器。
我的学习数据会被上传吗？
笔记、收藏、进度默认保存在本机配置目录，仅在需要账号同步时使用账号信息，不上传笔记内容。
内容会一直更新吗？
会。新增或改写的章节随版本发布，例如最近整篇重写了 Day 50「Zabbix 5.0 监控系统详解」，补齐了全栈部署、速查脚本与故障排查表。
